# Sieve - Image Viewer
---

### Install

```bash
# clone repo
git clone https://github.com/zakcole08/sieve.git
cd sieve
# compile
gcc sieve.c -o sieve -l SDL2
```

### Usage

```bash
./sieve <filename>
```

### Notes

- Currently only supports .ppm image format
